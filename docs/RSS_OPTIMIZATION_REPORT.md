### 📊 热度评分算法优化

#### 四维度评分体系:
1. **时间因子 (30%)**: 新闻时效性评分
   - 1小时内: 1.0分
   - 6小时内: 0.9分  
   - 24小时内: 0.7分
   - 超过24小时: 0.4分

2. **关键词因子 (25%)**: 财经关键词密度
   - 高影响关键词: +0.3分
   - 普通关键词: +0.1分/个

3. **标题因子 (20%)**: 标题重要性评估
   - 影响性词汇: "突破"、"暴涨"、"重大"等

4. **来源权威性 (25%)**: 基于新闻源分类
   - 官方媒体: 0.95分
   - 专业财经: 0.90分
   - 门户财经: 0.80分
   - 国际媒体: 1.00分
