## 🎯 主要功能

### 1. 📰 新闻数据获取
- **RSS源爬取**: 8个主要财经新闻源
- **备用数据**: 15条高质量样本新闻
- **热度评分**: 智能评分算法
- **格式化输出**: 便于分析的文本格式

### 2. 🧠 智能事件分析
- **输入**: 具体的新闻内容(一条或多条)
- **AI引擎**: DeepSeek API驱动
- **分析框架**: 事件-局面-结构-投资映射
- **输出**: 专业HTML分析报告

### 3. 🌐 Web界面集成
- **主页**: 事件分析输入页面
- **新闻页**: 新闻获取和预览页面
- **一键导入**: 从新闻页面直接导入数据到分析页面

## 🚀 使用方法

### 方法1: 快速启动脚本
```bash
./launch_integrated.sh
```

### 方法2: 直接启动Web系统
```bash
source .venv/bin/activate
python main_integrated.py
```

### 方法3: 仅使用新闻爬虫
```bash
source .venv/bin/activate
python -c "
from modules.news_crawler.crawler import NewsWebCrawler
crawler = NewsWebCrawler()
news = crawler.get_top_hotspots(limit=10)
for i, n in enumerate(news, 1):
    print(f'{i}. {n[\"title\"]}')
"
```

## 🎯 工作流程

3. **智能分析处理**:

4. **查看分析结果**:
