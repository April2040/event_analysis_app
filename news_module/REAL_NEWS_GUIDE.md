## 🔧 系统配置

### config.py 配置说明
```python
# 新闻源配置
NEWS_SOURCES = {
    "domestic": [...],      # 国内新闻源
    "international": [...]  # 国际新闻源
}

# 热度计算权重
HEAT_WEIGHTS = {
    "time_factor": 0.3,     # 时效性权重
    "keyword_factor": 0.25, # 关键词权重
    "title_factor": 0.2,    # 标题权重
    "source_factor": 0.25   # 来源权重
}
```
